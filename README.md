# Java Training
- Java 学習用リポジトリです。

## 学習方針
単にコードを動かすだけでなく、なぜその設計にするのか
- なぜその設計を採用するのか
- 例外や異常系をどのように扱うのか
- 保守性・可読性をどのように確保するのか   
を考えながら学習・検証を行っています。

## 目的
- Java の基礎構文の習得
- オブジェクト指向の理解
- ファイル入出力の学習
- 例外処理の学習
- シェルスクリプトによるビルド・実行の自動化

### ディレクトリ構成

### 学習内容
- Java 基本文法
- クラス設計
- コンストラクタ
- コレクション
- 例外処理
- ファイル操作
- CSVデータ処理
- ログ出力
- シェルスクリプトによる実行管理

### 実行方法
- コンパル  
bash *javac -d bin src/*.java*  

実行
java -cp bin *ain    
- ログ付き実行  

シェスクリプから実行し、ログ出力や異常終了判定を行います。   
bash ./run.sh
